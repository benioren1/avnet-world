# 🏙️ ארכיטקטורה חיה

משחק צוות: כל בוקר מנחשים מספרים אמיתיים מהמערכת, מרוויחים מטבעות לפי הקרבה לתשובה,
וקונים רכיבים אמיתיים של הארכיטקטורה. מי שבנה את העיר הכי שווה מוביל.

## הרצה בפיתוח

```bash
npm install
npm run server   # API על פורט 3001 (מדפיס את קישור המנהל)
npm run dev      # ממשק על http://localhost:5173
npm test         # בדיקות לוגיקת הניקוד
```

- **מנהל:** נכנסים ל-`#/admin` ומקלידים את קוד המנהל (`ADMIN_TOKEN`). הדפדפן זוכר אותו עד שלוחצים "🚪 התנתק".
  אחרי 5 קודים שגויים מאותה כתובת IP, הכניסה ננעלת ל-15 דקות (הפעלה מחדש של השרת משחררת).
- **שחקן:** כל שחקן מקבל קישור אישי `#/play?t=...` ממסך "שחקנים" בפאנל המנהל.

## מבנה

```
server/
  index.js         API: מנהל (שאלות, תשובות, שחקנים, ארכיטקטורה) ושחקן (ניחוש, קנייה, טבלה)
  store.js         שכבת נתונים: קובץ JSON מקומי, או MongoDB כשמוגדר MONGO_URL
  scoring.js       ניקוד לפי קרבה (פונקציות טהורות)
  scoring.test.js  בדיקות
src/
  admin/           פאנל המנהל: עורך ארכיטקטורה, שאלות ותשובות, שחקנים, הגדרות
  player/          מסך השחקן: היום, העיר שלי, חנות, טבלה
  model.js         סוגי רכיבים ומודל הנתונים של הארכיטקטורה
```

## העברה לרשת אחרת (בלי אינטרנט)

**דרישה:** Node.js בגרסה 22.9 ומעלה על השרת ברשת היעד (`node --version`).

1. **כאן, לפני ההעברה:** בעורך הארכיטקטורה לוחצים "💾 גיבוי לקובץ".
2. **כאן, במחשב עם אינטרנט:** `npm install`, ואז `npm run build`.
3. **מעבירים את כל התיקייה, כולל `node_modules` ו-`dist`.** אפשר בלי `data` ובלי `.env` של הפיתוח.
4. **ברשת היעד** יוצרים קובץ `.env` בתיקייה:

```
MONGO_URL=mongodb://user:pass@host:27017
ADMIN_TOKEN=קוד-מנהל-ארוך
PORT=8080
```

5. מריצים `npm start`, ובלוג אמורה להופיע השורה `store: mongo`.
6. נכנסים ל-`http://כתובת-השרת:8080/#/admin`, מקלידים את קוד המנהל, ובעורך לוחצים "📂 טעינה מגיבוי".
7. מוסיפים את השחקנים ושולחים לכל אחד את הקישור **החדש**.

שרת אחד מגיש גם את ה-API וגם את הממשק. כל השחקנים נכנסים לכתובת שלו.
כדי שהשרת ימשיך לרוץ אחרי ניתוק או הפעלה מחדש של המחשב, צריך להריץ אותו כשירות (systemd בלינוקס, או שירות Windows).

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `MONGO_URL` | (ריק = קובץ `data/db.json`) | חיבור ל-MongoDB |
| `MONGO_DB` | `architecture_game` | שם מסד הנתונים |
| `ADMIN_TOKEN` | נוצר אוטומטית ונשמר ב-DB | מפתח המנהל |
| `PORT` | `3001` | פורט השרת |
| `PUBLIC_URL` | `http://localhost:5173` | הכתובת שתודפס בקישור המנהל |
| `GAME_TZ` | `Asia/Jerusalem` | אזור הזמן לחישוב "היום" ושעת הנעילה |

> לא נדרשים פונטים או קבצים מהאינטרנט. הכל נארז ב-`dist`.

## חוקי הניקוד

| סטייה מהתשובה | נקודות |
|---|---|
| עד 2% | 100 |
| 10% | 80 |
| 25% | 50 |
| 50% | 20 |
| 100% ומעלה | 0 |

ביניהם הניקוד לינארי. בונוסים: הכי קרוב בשאלה +20, קרוב יותר מממוצע הצוות +10,
יום מושלם (כל השאלות בטווח 10%) +50. היתרה מחושבת תמיד מחדש (הרוויח פחות הוציא),
כך שפרסום חוזר של תשובות לא מכפיל נקודות.
